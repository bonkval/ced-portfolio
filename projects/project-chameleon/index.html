Project Chameleon

A bounded training sandbox for studying input-event normalization, buffering, timed flushing, and readable forensic records.

Python 3.10+CustomTkinterThreadingJSONSHA-256

Purpose

Input-event forensics is difficult to demonstrate responsibly when examples behave like unrestricted keyloggers.

Implementation

Built a consent-first controller and client with training-only windows, visible recording state, buffered logging, configuration, and forensic record review.

Implemented behavior

Handles spaces, backspaces, tabs, Enter, foreground-title records, and opt-in clipboard tests while excluding networking, global hooks, stealth, and autostart.

Run locally

Install requirements, run python run_chameleon.py, launch the client, accept the disclosure, and type only inside the Training Arena.
