Project Chameleon

A bounded training sandbox for studying input-event normalization, buffering, timed flushing, and readable forensic records.

Python 3.10+CustomTkinterThreadingJSONSHA-256
Purpose

Demonstrate forensics without becoming a global keylogger.

Project Chameleon is a consent-first keystroke forensics sandbox for cybersecurity portfolios. It demonstrates event normalization, memory buffering, timed flushing, readable logs, clipboard test events, threading, configuration, and a separate controller and client architecture.

Capture is restricted to the Training Arena and the separately launched Notes, Search, and Chat sandbox windows.

Review the source on GitHub ↗
System flow

Consent opens a deliberately narrow capture boundary.

ConsentCaptureBufferInspect

The controller manages configuration and forensic-log review. The client presents the disclosure, launches the isolated training windows, normalizes approved events, and flushes buffered records to a local activity log on a timer.

Recorded demonstrations

  • Spaces, backspaces, tabs, and Enter events
  • Foreground titles during an approved session
  • Visible, separately enabled clipboard test events
  • Thread-safe buffering and readable formatting
  • SHA-256 support for forensic record handling
Safety boundary

The controls stay visible throughout the session.

Every launch requires affirmative consent and the client keeps a persistent recording indicator visible. It can record foreground titles transparently, but it never captures input from unrelated applications.

Clipboard capture is a separate opt-in and is capped at 120 characters per event.

The project contains no networking, data exfiltration, global hooks, stealth window, registry writes, or autostart installation. Its persistence option creates an inert .reg.txt teaching artifact only.

Testing & limits

The demonstration remains local and inspectable.

The repository includes unit tests for the Chameleon modules and stores controller configuration in a local JSON file. The intended demonstration runs the controller and client side by side so the recording boundary and resulting forensic log remain obvious.

Project Chameleon is an educational sandbox for controlled input-event analysis. It is not designed for background monitoring, surveillance, remote collection, or deployment outside its included training environment.
