Codex Pulse

A lightweight Windows tray companion that makes Codex usage, live activity, and token history easier to read at a glance.

ElectronJavaScriptWindowsVS CodeLocal sessions

Purpose

Codex usage is easy to lose track of when limits, live activity, and session history are spread across separate surfaces.

Implementation

Designed and built the Electron tray companion, local session reader, usage refresh flow, token history, charts, alerts, theme support, and compact desktop interface.

Implemented behavior

Combines five-hour and weekly usage windows, current token activity, history charts, reset estimates, local exports, theme support, and optional notifications in one desktop surface.

Run locally

Install the Windows release, open Codex through VS Code, then open the tray companion to review usage and session activity. Use only your own local account data.
