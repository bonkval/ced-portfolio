Codex Pulse

A lightweight Windows tray companion that makes Codex usage, live activity, and token history easier to read at a glance.

ElectronJavaScriptWindowsVS CodeLocal sessions
Purpose

Make usage visible before it becomes a surprise.

Codex Pulse is a Windows companion for people who use Codex through VS Code and want a quick read on the limits that shape their work. It stays near the tray, showing rolling five-hour and seven-day usage alongside the current connection state.

The project turns a usually hidden account-and-session signal into a small, persistent desktop surface. The goal is awareness, not another full-size dashboard competing with the editor.

Review the source on GitHub ↗
Usage path

Two signals, one calm desktop view.

RefreshObserveExplainNotify

Account usage refreshes on a configured interval while local VS Code Codex session events update live activity, token counts, and the day’s history in about a second when data is available.

What the surface keeps close

  • Remaining five-hour and weekly usage windows
  • Current session input, output, reasoning, and total tokens
  • Today’s activity, seven-day and 30-day history charts
  • Usage pace estimates, streaks, and peak daily usage
  • Optional alerts for low usage, daily targets, and resets
Interface

Small enough to stay out of the way.

The app can sit in the tray, open as a compact floating logo, or expand into the usage view. It remembers its position across restarts and monitors, supports light, dark, and system themes, and includes a Codex Pet companion while Codex is working.

Charts, readable dates, hover details, connection health, sync time, and reset credits give the numbers context without forcing the user to inspect raw session files.

Privacy & limits

Local context, local processing.

Codex Pulse does not ask for or store API keys. It uses the existing local Codex login and reads session records from the user’s local Codex directory. The repository describes session data as processed locally rather than uploaded by the app.

Usage figures and activity depend on the Codex account state and local session events available on the machine. The companion makes those signals easier to see, but it cannot create data that Codex does not expose.

The project also supports local JSON and CSV exports for collected token history, plus release checks through GitHub for updates.
