Case study 03Behavioral decoy & early warning

Huli na!

A Windows-friendly SSH and HTTP decoy that records behavior without retaining passwords or request bodies.

PythonAsyncSSHSQLiteWindowsAnalytics
Purpose

Observe the touch without exposing the real system.

Huli na! is a GUI-first behavioral decoy for networks an operator is authorized to monitor. It exposes SSH and HTTP surfaces, records connection metadata, and turns observed behavior into severity-aware signals.

It is an early-warning sensor-not a firewall, identity system, or full intrusion-detection platform.

Review the source on GitHub ↗
Signal pipeline

Behavior becomes a score, then a reviewable record.

ObserveClassifyScoreReport

The application detects scanner, automation, exploit-path, burst, login, and cross-service signals. Scores produce Trusted, Informational, Suspicious, High, or Critical labels, while SQLite supports search, retention, analytics, and alert-delivery history.

Outputs

  • Windows and optional Discord notifications
  • CSV and JSON exports
  • Designed PDF incident reports
  • Rotating JSONL compatibility logs
  • Listener and alert self-tests
Privacy & safety

Enrichment is optional; sensitive content stays out.

The project does not retain submitted SSH passwords or HTTP request bodies. Offline scope detection stays local, and optional GeoLite2 lookups remain local when databases are provided.

AbuseIPDB checks are disabled by default. Private, loopback, multicast, and reserved addresses are never submitted.

When explicitly enabled, only eligible public source addresses are sent to the official reputation endpoint. Webhook storage can be protected with Windows DPAPI.

Testing

Failure modes are part of the design.

The tests cover scoring, trusted ranges, enrichment scope, SQLite, retention, connection limits, concurrent HTTP clients, exploit-path classification, and real SSH authentication rejection without password retention. GitHub Actions runs the suite on Windows and Linux.

The app can degrade safely when optional packages are absent: SSH falls back to a banner decoy, enrichment fields stay empty, and PDF export explains missing support.

Deployment boundary

Decoys belong in isolation.

Any internet-facing deployment should live in an isolated VM, container, or segmented VLAN with no sensitive data. Risk scores characterize observed evidence; they do not establish a person’s identity or intent.
