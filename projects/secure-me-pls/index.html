Case study 01Interactive password-security education

Secure me, pls?

A private browser experience that explains password advice through analysis, demonstrations, exercises, and practical account-security guidance.

Next.jsTypeScriptReact 19Tailwind CSSLocal storage
Purpose

Explain why password guidance works.

Secure me, pls? is an interactive learning experience for students and everyday internet users. It combines immediate password analysis with lessons that connect common advice to recognizable attack patterns.

The checker identifies length, character sets, common-password matches, keyboard walks, sequences, repeated patterns, dates, and predictable substitutions. Its feedback gives specific next steps instead of presenting an unexplained score.

Learning path

Analysis leads into practice.

AnalyzeExplainPracticeHarden

The Security Guide acts as a self-paced course covering password foundations, attack methods, passphrases, password managers, multi-factor authentication, passkeys, phishing, recovery, devices, and breach response.

Interactive exercises

  • Passphrase workshop using unrelated-word choices
  • Mutation demonstrations for predictable substitutions
  • Credential-reuse breach-chain simulation
  • Scenario questions with immediate feedback
  • Locally saved lesson progress and account-security checklist
Privacy model

Password input stays in the browser.

Analysis runs entirely on the client. Password input is not submitted to an API, written to a database, or sent to an external service by the project. Common-password data is bundled with the application.

Real passwords should not be entered into unfamiliar websites. This educational checker explains patterns; it cannot guarantee that a password is safe.

The deployed application adds a Content Security Policy, HSTS, clickjacking protection, MIME-sniffing protection, restrictive browser permissions, referrer controls, and removal of the framework-powered-by header.

Limits

A score cannot model every account threat.

A numeric result cannot account for every breach, targeted attack, phishing campaign, malware infection, or service-specific control. The project treats the score as a teaching aid and keeps broader protections such as unique credentials, MFA, passkeys, recovery planning, and device security in view.

The current site is statically rendered and requires no application database or environment variables.
