Secure me, pls?

A private browser experience that explains password advice through analysis, demonstrations, exercises, and practical account-security guidance.

Next.jsTypeScriptReact 19Tailwind CSSLocal storage

Purpose

Password advice is often reduced to an unexplained score, leaving people unsure which patterns actually weaken a password.

Implementation

Designed and built the private browser-based checker, learning guide, exercises, route structure, responsive interface, and security-focused deployment configuration.

Implemented behavior

Checks eight documented weak-pattern categories and delivers four focused routes with interactive lessons, exercises, scenarios, and a locally saved checklist.

Run locally

Open securemepls.vercel.app and use a made-up test password—never a real credential—then explore the Security Guide.
