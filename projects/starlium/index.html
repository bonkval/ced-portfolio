Starlium

A PHP footwear storefront connecting accounts, product discovery, checkout, inventory, user management, and administrator reporting.

PHPMySQLJavaScriptHTMLCSS
Problem

Connect the shopping flow to practical store administration.

Starlium brings the customer-facing catalog and checkout journey together with account handling, inventory maintenance, user administration, and sales-oriented reports.

Approach

One relational workflow from account to order.

BrowseCartCheckoutManage

Server-rendered PHP pages share authentication and database helpers, while MySQL stores the storefront data and JavaScript handles client-side interaction.
