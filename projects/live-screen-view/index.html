LiveScreenView

A lightweight way to capture a computer screen on demand, inspect it from a phone on the same network, and copy OCR-detected text.

PythonMSSPillowTesseract OCRLAN HTTP
Problem

Move visible screen information to a phone without a cloud service.

The project creates an intentionally small local-network workflow: capture only when requested, then view and extract text from another device connected to the same trusted network.

Approach

Capture, serve, zoom, and copy.

TriggerCaptureOCRView

The Python application uses MSS and Pillow for screen imagery, pynput for the capture shortcut, and Tesseract through pytesseract for selectable OCR output. The mobile viewer supports fit-to-screen and actual-size modes.
