Network
SecLab

A unified lab for guarded SSH configuration previews, SNMP event monitoring, authentication detection, and incident management.

PythonFlaskSQLiteSNMPDocker

Purpose

Students often lack managed network hardware for practicing monitoring, incident handling, and guarded configuration workflows.

Implementation

Built one local dashboard joining authentication monitoring, SNMP event handling, incident management, SSH previews, simulators, audit logs, and reports.

Implemented behavior

Provides three guided labs, five credential-attack detection patterns, a five-attempt/30-second brute-force threshold, and a real localhost SNMP datagram path.

Run locally

Run python start.py. The launcher creates its environment, installs changed dependencies, initializes databases, and opens http://127.0.0.1:5000.
