Network
SecLab

A unified lab for guarded SSH configuration previews, SNMP event monitoring, authentication detection, and incident management.

PythonFlaskSQLiteSNMPDocker
What it demonstrates

Hardware-free paths through realistic network operations.

The lab combines three guided experiences in one local web interface: authentication monitoring, SNMP event handling, and guarded configuration changes. Simulators make the workflows accessible without a managed switch.

GenerateDetectInvestigateResolve
  • SNMP v1/v2c trap decoding and community allow-listing
  • Five-attempt sliding-window authentication detection
  • Open, acknowledged, and resolved incident states
  • Configuration diff, backup, apply, validate, and rollback previews
  • Structured audit logs with SNMP credentials redacted
  • CSRF protection, password hashing, and secure sessions

Investigation

Raw events connect to an analyst workflow.

Local rules cover classic brute force, password spraying, credential stuffing, distributed password attacks, and imported Suricata alerts. Incidents include linked evidence, ATT&CK context when defensible, analyst notes, response recommendations, and downloadable reports.

Generic Suricata signatures remain marked “Unmapped” until an analyst assigns a defensible ATT&CK technique.

Boundaries

Configuration remains guarded.

The SSH workflow is inventory-driven and preview-first. It requires a running-configuration backup before a change and can demonstrate failed validation followed by rollback. The project is a learning environment and does not claim to replace mature network-management or SIEM platforms.
