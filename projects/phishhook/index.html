PhishHook

A consent-based training tool designed to make phishing-awareness campaigns reviewable, measurable, and deliberately limited.

Python 3.12+CustomTkinterCloudflare WorkersD1SQLiteSMTP

Purpose

Phishing-awareness demonstrations need measurable signals without collecting credentials or encouraging uncontrolled bulk campaigns.

Implementation

Built the desktop campaign workflow, review gates, SMTP integration, SQLite history, dashboard, and companion Cloudflare Worker with anonymous interaction events.

Implemented behavior

Enforces a 25-recipient cap, final review, no-credential education page, anonymous tracking signals, send-failure summaries, and demo mode without external services.

Run locally

Install the desktop package and run python -m antiphish in demo mode. Real sending requires documented authorization and separately supplied services.
