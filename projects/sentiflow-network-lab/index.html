SentiFlow

A local network-security lab that makes each detection step visible—from normalized evidence to an explainable verdict.

PythonSQLitePCAPTSharkHTML
Purpose

A network lab should show why a rule fired.

SentiFlow is a local, Windows-friendly threat monitor for authorized testing. It combines a SOC-style dashboard, deterministic traffic scenarios, PCAP ingestion, optional live capture, SQLite storage, and detection rules that expose their observed evidence and thresholds.

It requires no paid service or cloud account, and its built-in scenarios produce metadata records without scanning hosts, transmitting attack packets, executing malware, or replaying captured payloads.

Review the source on GitHub ↗
Detection path

One normalized pipeline for every input.

ReceiveNormalizeAnalyzeVerdict

Simulated events, recorded PCAP data, and optional live capture all enter the same normalized event pipeline. Validated events are stored, correlated, and evaluated before the system creates an incident.

Explainable scenarios

  • Port scanning and host discovery
  • SSH brute force behavior
  • Command-and-control-style beaconing
  • Possible data exfiltration
  • DNS tunnelling patterns
  • Threat-indicator matches
  • Normal browsing baseline
Validation

Detections can be tested, not merely displayed.

The Traffic Lab exposes editable JSON Lines events and lets an operator inspect exactly what enters the pipeline. The repository includes unit tests and a validation script that runs each labeled scenario and reports precision, recall, and a confusion matrix.

Detection thresholds remain configurable. Metrics describe the included scenarios and should not be generalized into unsupported real-world accuracy claims.

Optional TShark and Npcap integration can monitor an authorized interface, while recorded PCAPs can be analyzed without retransmission.

Limits

A lab environment, not a claim of complete coverage.

SentiFlow is designed for transparent testing and portfolio demonstration. Live capture depends on separately installed tools and may require elevated permissions. Runtime data stays in a local SQLite database excluded from version control.

Future work could expand protocol coverage, create more defensible benchmark datasets, and improve investigation workflows while preserving the system’s transparent rule explanations.
