CanvasCopyPasta

A local-only copy assistant for accessibility, study, review, and quizzes where AI assistance is explicitly permitted.

JavaScriptBrowser extensionShadow DOMClipboard APIAutoHotkey

Purpose

Canvas question content can be awkward to copy cleanly for accessibility, review, and explicitly permitted AI-assisted coursework.

Implementation

Built the Manifest V3 extension, isolated toolbar, active-question selection, text and image copying, configurable prompts, history, and optional school-origin access.

Implemented behavior

Supports text, prompt-appended text, single or combined images, selected radio and checkbox answers, persisted history, and user-approved Canvas origins.

Run locally

Open the browser extensions page, enable Developer mode, load the repository folder unpacked, and test only in an authorized Canvas workflow.
