CanvasCopyPasta

A local-only copy assistant for accessibility, study, review, and quizzes where AI assistance is explicitly permitted.

JavaScriptBrowser extensionShadow DOMClipboard APIAutoHotkey
Purpose

Copy the active question without cleaning it by hand.

CanvasCopyPasta, documented in the repository as Canvas Copy Assistant, places a compact toolbar beside the currently visible Canvas quiz question. It copies clean question text or appends a user-configurable prompt for workflows where AI assistance is allowed.

The extension is intended for convenience, accessibility, study, review, and explicitly AI-integrated assessments. It is not intended to bypass academic rules.

Review the source on GitHub ↗
Copy flow

The toolbar follows the question in view.

DetectCleanCopyConfirm

The extension selects the visible question nearest the center of the screen and responds to same-page question changes without relying on a one-second polling loop.

Handled content

  • Clean question text and an optional saved prompt
  • Selected radio and checkbox answers
  • Single images or multiple images combined into one PNG
  • Saved toolbar position, visibility, prompt, and copy history
  • Custom Canvas school origins approved by the user
Interface

Isolated from the page it assists.

The in-page toolbar uses an isolated Shadow DOM so Canvas styles do not alter its appearance. The interface supports keyboard focus, screen-reader labels, touch and pen dragging, clipboard error feedback, and a keyboard shortcut for hiding or showing the toolbar.

Users can grant access to another Canvas school through the extension popup. The extension requests only the origin the user approves.

Privacy & limits

Question content is processed locally.

Extraction occurs inside the page and clipboard writes happen only after the user selects a copy action. The project does not send question content to a server.

Canvas markup varies by institution and quiz engine. Separately hosted tools may require their own explicitly approved origin.

Compatibility work uses sanitized fixtures. Real active assessment content should never be uploaded to the repository or included in a bug report.
