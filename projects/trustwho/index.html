ProjectExplainable URL risk analysis

TrustWho

A local-first service that evaluates URLs without opening them, combining reviewed blacklists, optional URLhaus intelligence, and lexical machine learning.

PythonFastAPIscikit-learnPandasUvicorn
Problem

Analyze a suspicious URL without visiting it.

Opening or resolving an unknown address during classification can create unnecessary risk. TrustWho treats the URL as data, producing a reviewable verdict while avoiding live-page retrieval.

Approach

Three layers, one explainable result.

NormalizeBlacklistClassifyExplain

The service checks exact URLs, domains, and carefully selected substrings before optional URLhaus lookup and inference from a 34-feature lexical classifier. Model artifacts use a restricted loading path rather than trusting arbitrary serialized objects.
