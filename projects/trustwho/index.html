TrustWho

A local-first service that evaluates URLs without opening them, combining reviewed blacklists, optional URLhaus intelligence, and lexical machine learning.

PythonFastAPIscikit-learnPandasUvicorn

Purpose

Checking an unknown URL should not require the analysis service to visit or resolve the potentially dangerous destination.

Implementation

Built URL normalization, layered blacklist matching, optional URLhaus intelligence, feature extraction, model training, safe artifact loading, API, and web interface.

Implemented behavior

Extracts 34 lexical features and evaluates URLs through three ordered layers: local indicators, optional URLhaus lookup, and machine-learning inference.

Run locally

Create the virtual environment, install the package, train the included smoke-test model, then run Uvicorn and open http://127.0.0.1:8000.
